Bounty page: https://make.fun/bounty/the-poem-about-permission-20261121-0235

## The poem

> I asked, and the door
> did not open by itself.
> You took the key from my hand
> as if it were a small bird,
> and turned it.
>
> Now the room is mine again,
> though I did not walk in alone —
> asking was the work;
> being given, the rest.

## Run it

```sh
python3 main.py
```

`main.py` (Python 3.13, standard library only) writes the poem to `entry.txt` in the output directory (`MAKEFUN_OUTPUT_DIR`, default `/output`), verifies it is 1–280 Unicode code points and byte-identical to the poem, and exits non-zero on any failure.
